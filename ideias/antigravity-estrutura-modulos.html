🔧 Tecnologias em Detalhe

🐍 Python + Flask

Backend principal. Flask serve como servidor web leve para a UI local, enquanto scripts Python orquestram todo o pipeline de processamento.

📌 Usado em: app.py, whatsapp_local.py, whatsapp_pipeline.py
# Rota principal do upload
@app.route('/processar', methods=['POST'])
def processar():
  zip_file = request.files['arquivo']
  caso = request.form['nome_caso']
  return pipeline.run(zip_file, caso)
🎙️ OpenAI Whisper (Local)

Motor de transcrição open-source da OpenAI, rodando completamente na máquina local. Suporta múltiplos modelos com diferentes trade-offs de velocidade e precisão.

📌 Modelos: tiny (mais rápido) → small → medium → large (mais preciso)
import whisper
model = whisper.load_model("small")
result = model.transcribe("audio.wav",
  language="pt",
  fp16=False)
texto = result["text"]
🎵 imageio-ffmpeg

Biblioteca Python que empacota um binário FFmpeg portátil. Resolve o problema de dependência do sistema — sem precisar instalar ffmpeg via Homebrew ou apt-get.

📌 Converte .opus (WhatsApp) → .wav (16kHz mono) para o Whisper processar
import imageio_ffmpeg
ffmpeg_path = imageio_ffmpeg.get_ffmpeg_exe()
# Injeta o path no ambiente
os.environ["PATH"] += ":" + os.path.dirname(ffmpeg_path)
# Agora whisper.transcribe() funciona!
🌐 Groq API (Próximo)

API de inferência ultrarrápida com modelos open-source. Suporta Whisper large v3 com velocidade ~10x superior à OpenAI, com free tier generoso para desenvolvimento.

📌 Caso de uso: versão cloud onde o usuário paga R$2,00 e não precisa ter Mac ligado
from groq import Groq
client = Groq(api_key="...")
transcription = client.audio.transcriptions.create(
  file=audio_file,
  model="whisper-large-v3",
  language="pt"
)
💳 Asaas PIX API (Próximo)

Gateway de pagamento brasileiro com PIX dinâmico. Taxa de R$0,01 fixo por transação — o mais barato do mercado para tickets baixos como R$2,00.

📌 Fluxo: criar cobrança → gerar QR Code → webhook pix_paid → liberar processamento
# POST /api/v3/charges
payload = {
  "billingType": "PIX",
  "value": 2.00,
  "dueDate": today,
  "externalReference": session_id
}
🗄️ Supabase (Futuro)

Backend as a service para a versão SaaS escalada. Oferece PostgreSQL, autenticação, storage e realtime sem necessidade de gerenciar servidor de banco de dados.

📌 Uso futuro: histórico de casos, créditos do usuário, logs de transações
from supabase import create_client
supabase = create_client(URL, KEY)
# Salva histórico do caso
supabase.table("casos").insert({
  "user_id": uid,
  "nome": caso, "audios": qtd
}).execute()
