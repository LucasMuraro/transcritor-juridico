⚖️ Regras de Ouro da Arquitetura (Invioláveis)

🏢 Multi-Tenant Nativo

Toda tabela DEVE ter empresa_id. É a regra #1. Sem ela o sistema não separa os 10 CNPJs.

🔒 Row Level Security (RLS)

O banco de dados bloqueia fisicamente uma filial de ver dados de outra. Não filtre só no React.

🗑️ Soft Delete Obrigatório

NUNCA use DELETE SQL. Use status = 'inativo' ou deleted_at para manter auditoria fiscal e histórico SST.

🔑 Zero Credenciais no Git

Chaves Supabase, certificados A1, tokens Itaú — tudo em .env e Vercel Secrets. Nunca no código.

⚡ NF Assíncrona (Webhook)

Emissão de NF não pode travar a tela. Envie o pedido, o Gateway avisa quando a SEFAZ aprovar.

🔄 SOC: Sincronização Periódica

Não chame a API do SOC em tempo real. Sincronize de madrugada via Edge Function e salve no Supabase.

🛡️ mTLS para APIs Bancárias

O Itaú exige autenticação mútua. Configure o certificado no backend (API Route/Edge Function), nunca no browser.

📄 CONTEXT.md como Memória

Toda regra de negócio da SafeWork fica num CONTEXT.md na raiz. A IA lê isso a cada sessão de desenvolvimento.
