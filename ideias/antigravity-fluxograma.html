⚙️ Pipeline Técnico Detalhado — Passo a Passo

📦

Etapa 1 — Recepção do arquivo .zip

O usuário faz upload do arquivo exportado pelo WhatsApp. O backend salva temporariamente em /uploads/temp_{uuid}/.

Flask POST /upload multipart/form-data zipfile.extractall()
📄

Etapa 2 — Parser do _chat.txt (filtro por data)

Lê o arquivo de texto principal da conversa. Usa regex para identificar mensagens, remetentes e os nomes dos arquivos de áudio. Filtra apenas o período selecionado pelo usuário.

regex · datetime whatsapp_local.py Padrão: [DD/MM/AAAA HH:MM] Nome: mensagem
🎵

Etapa 3 — Extração e conversão dos áudios .opus

Identifica quais anexos de áudio (.opus) correspondem ao período filtrado. Converte cada arquivo de .opus para .wav usando imageio-ffmpeg embutido — sem depender do ffmpeg do sistema.

imageio-ffmpeg .opus → .wav (16kHz mono) Sem instalação de ffmpeg no sistema
🤖

Etapa 4 — Transcrição com Whisper

Cada arquivo .wav é enviado ao motor Whisper. O modelo retorna o texto transcrito em português (ou idioma detectado automaticamente). Roda localmente no Mac ou via API na versão cloud.

openai-whisper (local) Groq API (cloud) modelo: small → 39x faster language: pt auto-detect
📋

Etapa 5 — Consolidação Cronológica

O sistema cruza o _chat.txt original com as transcrições geradas, montando uma linha do tempo única: cada entrada tem data, hora, remetente, tipo (texto ou áudio) e conteúdo.

Formato: [Data Hora] Remetente — Texto / 🎙️ Transcrição Ordenação cronológica garantida
📤

Etapa 6 — Geração do Relatório Final

Exporta o resultado em .txt formatado (atual) ou .pdf (futuro). Na versão local, abre automaticamente a pasta 05_consolidado/ no Finder. Na versão cloud, gera link de download temporário.

Output: TRANSCRICAO_{caso}_{data}.txt Futuro: PDF com cabeçalho jurídico Deleção automática após download (cloud)

⚠️ Tratamento de Erros & Edge Cases

📦 Erros no Upload

Arquivo não é um .zip → exibir erro
.zip não contém _chat.txt → inválido
Arquivo muito grande (>500MB) → avisar e limitar
Sem áudios no período → "Nenhum áudio encontrado"
Timeout de upload → retry automático

🤖 Erros na Transcrição

ffmpeg não encontrado → usar imageio-ffmpeg embutido
Áudio corrompido → marcar como ⚠️ ERRO no output
Modelo Whisper não carregado → baixar automaticamente
Memória insuficiente → usar modelo smaller
API indisponível → fallback para Groq

💳 Erros no Pagamento

PIX expirado (>30min) → regenerar QR Code
Webhook não recebido → polling periódico
Pagamento cancelado → liberar arquivos temp
Duplo pagamento → detectar via txid único
Chargeback → logs auditáveis

🔐 Erros de Segurança & LGPD

Download expirado → token de 1 uso apenas
Acesso não autorizado → JWT/session validation
Arquivos não deletados → cron job de limpeza
Conteúdo sensível → nenhum log de transcrições
Rate limiting → max 50 uploads/hora por IP
